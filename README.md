# 🧾 Job Data Manager

A lightweight web app for managing job listings for **Data Engineers** and **Software Engineers**, saving entries directly into an Excel file with role-specific sheets.

![App Screenshot](images/screenshot.png) <!-- Replace with your actual screenshot path -->

---

## 🔧 Features

- 🌐 Single-page web app with clean UI
- 📝 Input company name, location, skills, and job description
- 📂 Select role: Data Engineer or Software Engineer
- 📊 Saves data into a single Excel file with two sheets
- 📦 Bulk add multiple companies with role selection
- 💾 Backend powered by Flask and Excel (via openpyxl)
- ✅ Runs completely on local machine
